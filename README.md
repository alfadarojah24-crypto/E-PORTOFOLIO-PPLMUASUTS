# E-Portofolio PPL Mandiri – Nurudlucha Alfa Darojah

PPG Teknik Mesin, Universitas Negeri Malang · PPL Mandiri di SMK Negeri 6 Malang (CNC CAD/CAM Mastercam X5).

## Struktur
```
index.html          halaman e-portofolio (foto sudah tertanam)
video/              4 video (pembelajaran dan kunjungan industri)
dokumen/            Modul Job 1–4 dan LK 4.1 Siklus 1–4 (PDF)
.nojekyll           agar GitHub Pages menyajikan file apa adanya
```

## Cara tayang di GitHub Pages
1. Buat repositori baru di GitHub (publik), misalnya `e-portofolio`.
2. Klik **Add file → Upload files**, lalu seret isi folder ini (`index.html`, `video`, `dokumen`, `.nojekyll`, `README.md`). Jangan unggah file zip-nya.
3. Klik **Commit changes**.
4. Buka **Settings → Pages**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
5. Tunggu 1–2 menit. Alamatnya: `https://<username>.github.io/e-portofolio/`

Catatan: nama file dan folder harus tetap sama karena halaman memanggilnya lewat path relatif. Batas unggah lewat browser adalah 25 MB per file; semua file di sini di bawah itu.
